# NOVABot Colombia — Archivos del Proyecto

## ¿Qué es cada archivo?

### 📁 Carpeta raíz (la principal)
- package.json → Le dice a internet qué tipo de proyecto es
- .gitignore → Le dice a GitHub qué archivos NO subir (protege tu clave)
- .env.example → Ejemplo de cómo guardar tu API Key (no subir el real)

### 📁 Carpeta pages/
- index.js → La página principal con menú de herramientas

### 📁 Carpeta pages/api/
- chat.js → EL MÁS IMPORTANTE: protege tu API Key de Anthropic

### 📁 Carpeta components/ (todas las herramientas)
- novamoda-colombia.jsx → Landing page para mostrar a clientes
- novabot-admin.jsx → Tu panel de administrador
- novabot-panel-cliente.jsx → Panel que ve cada cliente
- novabot-kit-ventas.jsx → Guiones, contratos y propuestas
- novamoda-recomendador-planes.jsx → Cuestionario de planes
- novamoda-operaciones.jsx → Control de cobros
- novamoda-negocio-completo.jsx → Contratos y prospección
- novafit-ropafit-demo.jsx → Demo ropa deportiva
- novabusiness-mayorista-accesorios.jsx → Demo mayorista y celulares
- guia-asesor-ventas.jsx → Cómo contratar tu equipo
- guia-whatsapp-twilio.jsx → Conectar WhatsApp real
- novabot-guia-lanzamiento.jsx → Guía para publicar
